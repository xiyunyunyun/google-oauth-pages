# vps-nai-gdrive-backup

Public homepage and privacy policy for the personal `vps-nai-gdrive-backup` Google OAuth application used with rclone and Google Drive.

## Files

- `index.html` — public application homepage
- `privacy.html` — public privacy policy
- `google328de3063db88ba9.html` — Google site-ownership verification file; keep the filename and contents unchanged

## GitHub Pages

Publish the repository root from the `main` branch with GitHub Pages.

- https://xiyunyunyun.github.io/google-oauth-pages/
- https://xiyunyunyun.github.io/google-oauth-pages/privacy.html
- https://xiyunyunyun.github.io/google-oauth-pages/google328de3063db88ba9.html

## Google OAuth configuration

Use the same application name in Google Cloud and on the homepage:

`vps-nai-gdrive-backup`

Configure:

- Homepage: https://xiyunyunyun.github.io/google-oauth-pages/
- Privacy Policy: https://xiyunyunyun.github.io/google-oauth-pages/privacy.html

The Google verification HTML file is an ownership token and must not be replaced with normal page content.
