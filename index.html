vps-nai-gdrive-backup

A personal VPS backup utility that uses the Google Drive API through rclone to store backups in the owner's Google Drive account.

Personal use: This application is operated for the owner's own backup workflow. It is not a public cloud storage service, does not provide accounts to third parties, and does not sell or monetize Google user data.

Purpose

vps-nai-gdrive-backup is used to back up files from a VPS server to Google Drive. The application provides the OAuth identity and privacy information required for an authorized connection between the owner's rclone installation and the owner's Google Drive account.

How it works

  1. The owner configures rclone on the VPS.
  2. The owner authorizes access to their Google account through Google OAuth 2.0.
  3. rclone uses the resulting authorization to perform the Google Drive operations needed for backup and synchronization.
  4. Backup files are stored in the owner's Google Drive account.

Google user data

Depending on the owner's rclone configuration, the backup workflow may access Google Drive file and folder metadata and the contents of files that the owner chooses to back up, restore, synchronize, or manage.

This static website does not itself receive, store, or sell the owner's Google Drive files. OAuth credentials and tokens used by rclone are handled by the owner's rclone installation and local environment.

Data use and sharing

  • Google user data is used only to provide the requested backup and file-management functionality.
  • Google user data is not sold, rented, or used for targeted advertising.
  • Google user data is not provided to data brokers or information resellers for their independent use.
  • Google user data is not used to determine credit-worthiness, lending eligibility, or similar financial decisions.
  • Google user data is not used to develop, improve, or train generalized or non-personalized AI/ML models.
